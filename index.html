What this does — and doesn't

It makes one ordinary visit to the site you type and reads the version the server publishes in its response headers — the same thing any browser already sees. It never attempts the vulnerability, never logs in, and never scans anything else. If your server hides its version (it should), the check tells you so and what to do next.
